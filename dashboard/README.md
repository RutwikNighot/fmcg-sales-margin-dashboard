# Dashboard outputs

- `charts/` — PNG exports of the four core charts, generated by
  `notebooks/02_analysis_and_forecast.py`. Use these for a quick look
  or to embed in a resume/portfolio page without opening Power BI.
- `powerbi_ready_data.csv` — the full cleaned dataset, ready to import
  directly into Power BI Desktop or Tableau Public to build the
  interactive version of the dashboard.
- `findings.txt` — plain-text summary of the four key findings,
  regenerated each time the analysis script runs.

## Building the interactive dashboard

1. Open Power BI Desktop → Get Data → Text/CSV → select `powerbi_ready_data.csv`.
2. Build four visuals:
   - Line chart: `order_month` (x) vs `revenue` (y)
   - Bar chart: `region` (x) vs `revenue` (y), with `margin_value` as a
     secondary measure
   - Bar chart (top N filter = 10): `client_name` vs `revenue`
   - Bar chart: `product_category` vs average `base_margin_pct`
3. Publish to Power BI Service for a shareable link, or export key
   visuals as images if sharing the .pbix file isn't convenient.
